# Android build

The Android app is a Capacitor 8 project in `android/` (package `ph.jeepneyrush.game`;
**change `appId` in `capacitor.config.ts` and `applicationId`/`namespace` in
`android/app/build.gradle` to your own before publishing**).

## Requirements
* Node 20+ and npm
* Android Studio (Ladybug or newer) with Android SDK 36 and JDK 21
* A device or emulator with Android 7.0+ (API 24). WebGL 2 is used when available.

## Debug build
```bash
npm install
npm run android:sync      # vite build + copy web assets & plugins into android/
npm run android:open      # opens Android Studio → Run ▶
# or, from the CLI:
cd android && ./gradlew assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

## Release build (AAB for Google Play)
1. Create an upload key once (keep it safe and back it up):
   ```bash
   keytool -genkeypair -v -keystore jeepney-rush-upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
   ```
2. Create `android/keystore.properties` (git-ignored):
   ```properties
   storeFile=/absolute/path/to/jeepney-rush-upload.jks
   storePassword=…
   keyAlias=upload
   keyPassword=…
   ```
3. Bump `versionCode` / `versionName` in `android/app/build.gradle`.
4. Build:
   ```bash
   npm run android:sync
   cd android && ./gradlew bundleRelease
   # → android/app/build/outputs/bundle/release/app-release.aab
   ```
5. Enrol in **Play App Signing** when you upload the first AAB.

## What's configured
* Portrait lock (manifest + `@capacitor/screen-orientation`), fullscreen theme, display-cutout aware layout (`safe-area-inset` in CSS).
* Hardware acceleration on; `VIBRATE` permission for haptics.
* Lifecycle: pause on background, audio suspend, Android back button handling.
* Launcher icons (legacy, round, adaptive) and splash images are generated by `node scripts/generate-assets.mjs` from `public/icon.svg`.

## Store assets
`store/icon-512.png` and `store/feature-graphic-1024x500.png` are generated.
Take phone screenshots on a device, or use `SHOTS=1 npm run test:e2e` for 405×720
captures as a starting point. Play needs at least 2 screenshots, 320–3840 px.
The full release checklist (privacy policy, data safety form, content rating,
testing tracks) is part of Phase 5 in `docs/ROADMAP.md`.
